一、适用范围

本政策适用于《我的奶茶小店》的 TapTap 小游戏版本，以及使用本政策的 Android、iOS 和桌面版本。仅某一平台或已启用功能涉及的信息处理，不适用于其他平台或未启用的功能。

TapTap 平台账号、平台实名认证、下载与运行环境等由 TapTap 提供的服务，以及您通过广告或外部链接访问的服务，另由相应服务提供者按其隐私政策处理信息。您可以通过本政策中的链接查阅相关规则。

二、信息的处理与用途

1. 本地游戏进度

为了保存进度、恢复经营状态并计算离线收益，本游戏在本地保存金币、销售与服务统计、配方及熟练度、设备和装修等级、员工数量、任务领取记录、奖励状态、增益剩余时间、保存时间和离线结算时间等游戏数据。TapTap 小游戏使用宿主提供的本地存储，原生及桌面版本使用系统中的本地应用存储。

这些存档不会由游戏业务代码主动上传到开发者服务器，也不与开发者自建账号绑定。不同平台与设备的存档相互独立；清理游戏数据、清除宿主缓存或卸载应用可能导致进度丢失，具体以设备和平台行为为准。

2. 运行环境与诊断信息

为了适配画面与安全区，本游戏会在运行时读取屏幕或窗口尺寸、安全区、界面菜单区域以及前后台状态。为了排查加载与运行问题，会产生启动阶段耗时、存档错误、异常信息及 SDK 状态等诊断日志。游戏业务代码未接入向开发者服务器自动上传这些日志的服务；平台或 SDK 自身的日志处理见第三节。

3. 原生版本的随机广告请求标识

Android/iOS 原生版本会在本地生成并保存一个随机标识，用于广告请求及奖励对应。该标识由程序随机生成，不读取姓名、手机号或硬件标识；它仍可能在与其他信息关联时属于个人信息。当前广告未启用时，该标识不通过本游戏的广告请求发送；若后续启用原生广告，会随相关请求提供给广告 SDK。

4. 您主动联系时提供的信息

如果您通过邮箱反馈问题或提出个人信息请求，我们会处理您的邮件地址、邮件内容，以及您自愿提供的截图、日志或其他材料，用于回复、排查和处理请求。请尽量只提供必要信息，勿发送密码、验证码或无关的身份证件信息。

本游戏业务功能不要求您提交姓名、手机号、身份证号、通讯录或支付信息，也未提供开发者自建的账号登录、聊天或真实货币购买功能。平台自身提供的功能不属于本项说明的范围。

四、权限与广告选择

当前游戏业务功能不主动申请通讯录、摄像头、麦克风、电话状态或精确位置等运行时权限。本地存档使用应用或宿主的存储能力；平台及 SDK 可能使用网络访问、网络状态等能力，具体以所使用版本和系统展示为准。

您可以在设备系统或 TapTap 平台设置中管理授权。若拒绝某项可选权限，仅相关功能可能受影响。当前版本未提供真实广告或个性化广告功能，因此没有游戏内个性化广告开关。后续如启用，将在启用前披露相关处理并提供适用的授权与选择方式。

本政策页面本身不构成系统权限授权或广告跟踪同意；相关授权应通过对应功能和平台流程完成。

五、共享、转让与公开披露

我们不出售您的个人信息。除本政策说明的平台与 SDK 服务、您主动要求或同意的处理，以及法律法规要求的情形外，我们不向其他主体提供您的个人信息，也不公开您的本地存档或反馈邮件。

若发生涉及个人信息的运营主体变更或资产转让，我们将依法告知相关情况，并要求接收方继续按本政策保护信息；处理目的或方式发生变化时，将依法重新取得必要授权。依法需要披露时，我们会核实要求并控制披露范围。

六、存储期限与安全

本地存档和随机标识保存在您的设备或 TapTap 宿主的应用存储中，通常保留至您清除相应数据；我们未为其建立开发者云端副本。运行日志的保存期限由设备、宿主或日志环境决定，平台和 SDK 的服务器存储地点与期限请查阅各自政策。

您主动发送的反馈和权利请求材料，仅在回复、解决问题及履行必要义务所需的期间保留；目的完成后，我们会删除或匿名化处理，法律法规要求继续保留的除外。

我们采取与信息处理相适应的保护措施，并尽量减少处理范围。本地存档的校验与备份槽用于发现损坏和恢复进度，不属于加密或身份认证措施。请保护设备和平台账号，谨慎共享存档与日志。如发生影响您个人信息安全的事件，我们将依法采取补救措施并履行必要的通知义务。

七、您的信息权益

  • 查阅与复制：您可在游戏界面查看进度。若需要了解我们处理的反馈材料或提出复制请求，请通过隐私邮箱联系。
  • 更正与删除：您可要求更正或删除向我们提供的信息。本地游戏数据可通过设备或宿主提供的数据清理方式删除；清理会影响游戏进度，操作前请确认对应数据范围。
  • 撤回授权：您可通过设备和平台设置撤回相应授权。撤回不影响此前已依法进行的处理；我们不再处理依赖被撤回授权的新信息。
  • 停止使用与账号注销：您可以停止使用本游戏。游戏没有开发者自建账号，因此无需注销游戏账号；TapTap 平台账号的注销应通过平台提供的渠道进行。
  • 平台或 SDK 信息请求：对于第三方持有的信息，您可通过其官方政策中的渠道提出请求，也可联系我们协助。

我们会在收到请求后核实必要信息，并通常在 15 个工作日内回复。身份核验仅限于请求所需范围；若法律法规规定无法满足请求，我们会说明原因。

八、未成年人保护

未成年人应在监护人指导下阅读本政策并使用游戏；不满 14 周岁的儿童涉及个人信息处理时，应取得监护人的同意。游戏不会主动要求儿童提交身份或联系方式。TapTap 平台依法开展的实名认证及未成年人保护流程，由平台按照其规则提供。

若您是监护人，认为我们在缺乏必要同意的情况下处理了儿童个人信息，请通过隐私邮箱联系我们。我们核实后会依法采取删除等措施。未成年人发送反馈时，请勿提供不必要的身份、学校或住址信息。

九、隐私政策网页

本网页由 GitHub Pages 托管，不包含广告、分析脚本、第三方字体、表单或由开发者设置的 Cookie。访问网页时，GitHub 可能为提供网站、安全防护及履行义务处理访问 IP 地址等技术信息；此处理适用 GitHub 隐私声明，其托管服务可能涉及境外处理。

阅读本网页不会上传您的游戏存档。点击第三方政策链接后，相应网站按其政策处理访问数据。

十、政策更新与联系我们

当游戏功能、第三方接入或信息处理方式变化时，我们会更新本政策并标注日期。涉及处理目的、信息种类或您权益的重大变化时，我们会通过适当方式告知，并依法取得必要授权；不会仅以您继续使用作为一切新增处理的同意。
